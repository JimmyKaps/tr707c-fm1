# TR-707C

A drum machine for the M-VAVE FM-1 in the look and workflow of a 1985 computer rhythm composer: beige case, orange and
black lettering, a green LCD, 16 step keys. An unofficial fan firmware, not made, endorsed or supported by Roland or
M-VAVE. It is an app on the Dinghy platform (Felucca / SLOOP, GPL-3.0): `firmware/src/tr707c.c`.

- **13 instruments:** BD SD LT MT HT RIM CLAP COW CH OH CRASH RIDE TAMB, synthesised with integer maths (no samples).
- **A pattern of up to 64 bars (1024 steps) for every instrument**, each with its own loop length of 1..64 bars, so a
  3-bar cowbell can run against a 64-bar kick. Three levels per step: off, on, accent.
- **MIDI:** notes, three banks of 13 CCs and global CCs, clock in and out, start/stop. Made for a controller like the
  Arturia KeyStep.
- **8 songs**, saved to flash (one 4 KB blob each).

## Panel

| Control | Does |
| --- | --- |
| 16 white keys (STEP mode) | the 16 steps of the bar on screen: tap off > on > accent (a lit key = accent, dim = on) |
| black keys (STEP mode) | play the selected instrument |
| keys F3..F4 (PAD mode, `SEL`) | the 13 instruments; with `REC` armed and the sequencer running they write into the pattern |
| `ENC_SELECT` | instrument |
| `ENC_ALGORITHM` | bar on screen (1..64) |
| `ENC_PRESETS` | loop length of the instrument (1..64 bars) |
| `KNOB1` / `KNOB2` | tempo (40.0..240.0) / swing (50..75 %) |
| `KNOB3` / `KNOB4` | level / tune of the instrument. Page 2 (`EDIT`): decay / global accent |
| `PLAY` / `REC` | start, stop / arm live recording |
| `SEL` | STEP / PAD mode |
| `FX` | mute the instrument |
| `SEQ` | clear the instrument (press twice) |
| `ARP` | copy this bar to the next one |
| `LFO` / `GLO` | clock source INT / EXT, MIDI clock out on / off |
| `OCT-` `OCT+` / `SAVE` / `HOME` | song 1..8 / save the song / load it (stops the sequencer first: a flash erase stalls the sound) |
| `MASTER` | volume (platform) |

Song 1 is loaded at power-on if one was saved, otherwise the demo pattern plays when you press PLAY.

## MIDI

Notes: **36..48** (C1..C2) play the 13 instruments in the order above, on any channel. On **channel 10** the General MIDI
drum map is used instead (36 BD, 38 SD, 41 LT, 45 MT, 48 HT, 37 RIM, 39 CLAP, 56 COW, 42 CH, 46 OH, 49 CRASH, 51 RIDE,
54 TAMB). Velocity 110 and above is an accent. Every hit the sequencer plays also goes out on channel 10 (USB).

| CC | Function | | CC | Function |
| --- | --- | --- | --- | --- |
| 1 | swing | | 80 | select instrument |
| 7 | master volume | | 81 | bar on screen (1..64) |
| 14 | tempo 40..240 | | 82 | loop length of the selected instrument (1..64 bars) |
| 15 | accent amount | | 83 | record arm (>= 64) |
| **20..32** | **bank A: level** of the 13 instruments | | 84 | clear the selected instrument (>= 64) |
| **40..52** | **bank B: tune** (64 = centre, +-1 octave) | | 85 | mute the selected instrument (>= 64) |
| **60..72** | **bank C: decay** (x0.25..x2.5) | | 86 | clock source: >= 64 external |
| | | | 120 / 123 | all sound / notes off |

Real-time: `0xF8` clock (24 per quarter, a step every 6), `0xFA` start, `0xFC` stop. With `GLO` on, the internal clock is
sent as `0xF8` with start and stop. Songs are not selected by program change.

### Arturia KeyStep

I could not find documentation of a "CC bank" on the KeyStep models, so the numbers above are the firmware's fixed
table and the KeyStep side is yours to assign in Arturia's **MIDI Control Center**: send each knob, fader or pad the CC
you want from the table (for a unit with 8 knobs: bank A = CC 20..27, with a second page for 28..32, and so on). The
keyboard plays instruments with no setup: set it to channel 1 (chromatic from C1; octave button to reach C1..C2) or to
channel 10 for the GM map. The KeyStep's own sequencer and arpeggiator can drive the drums too, and its clock can run the
TR-707C: switch `LFO` to EXT, press play on the KeyStep.

## Build

```sh
tests/run_host_tr707c.sh tests/tr707c_demo.txt   # no FM-1 needed: build/host/tr707c.wav and the screens as PNG
tools/get_toolchain.sh                           # once, see README.md
./build.sh --app tr707c                          # -> build/tr707c.fwsc
python3 tools/fm1_install.py build/tr707c.fwsc   # over USB
```

`tools/gen_tr707c_tables.py` writes `firmware/gen/tr707c_tables.h` (pitches, decay and tune tables) so the chip never needs
a float or an `exp`. The package identity is `FM-1_950` (`APPS` in `tools/build.py`): check the
[FM-1 Firmware Hub](https://thefirmwarehub.com) list before a public release, and pick another if it is taken.

## Status

Tested on a computer only (host mode: `tests/tr707c_demo.txt` runs the panel, MIDI notes and CCs, live record, a 64-bar
loop, external clock, save/load; the sound is rendered to a WAV and the screen to PNGs). **Not built with the JieLi
toolchain and not run on an FM-1 yet.** Still to check on the device: that `./build.sh --app tr707c` passes the build's
checks, the audio ISR's load with many voices at once (host mode cannot measure it), the loader screen, and the real feel
of the keys and encoders. Installing firmware is at your own risk; the USB rescue (hold `OCT-` at power-on) and the
hub's one-click return to official firmware are described in the README.
